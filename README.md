# Project-iqbal-2.o
# 🎓 PROJECT IQBAL — Human × AI Exam Academy

**Project Iqbal 2.0** ek free, modern aur responsive learning platform hai jo competitive exams (SSC, UPSSSC, UP Police, Railway, Banking, Teaching) ki taiyari ke liye banaya gaya hai.

---

## 🌟 Features

- **📱 Responsive Dark Theme:** Mobile, Tablet aur Laptop sabhi par smooth look.
- **📚 Syllabus & Lessons:** Subject-wise topics aur detailed study material.
- **🇮🇳 Constitution Special:** Indian Polity ke Important Articles, Schedules aur Notes.
- **⚡ Practice & Mock Tests:** Topic-wise questions solve karo real-time answer feedback aur explanation ke sath.
- **📝 Personal Notes:** Apne revision notes save, edit aur search karo.
- **📊 Daily Target & Progress:** Daily target set karo, accuracy track karo aur backup (Export/Import) download karo.

---

## 🛠️ Tech Stack

- **HTML5:** Clean structure with accessibility.
- **CSS3:** Custom Variables, Flexbox, Grid & Media Queries.
- **JavaScript (ES6+):** Pure Vanilla JS (No external libraries).
- **LocalStorage API:** Progress aur notes offline save rakhne ke liye.
